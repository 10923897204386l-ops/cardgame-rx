# M0.1H — Save/resume and card-lighting report
Date: 2026-11-20. Branch: `feat/m0-1h-saves-card-lighting`.

## Baseline
- Spec taken from `origin/main` commit `92d1ad7` (`tasks/M0.1H-SAVES-CARD-LIGHTING.md` plus the HUD, felt-base and global-quit addenda).
- Implementation started from `feat/card-fronts-v1-25pct`, which already carried the approved 25%-larger top-left index deck and the M0.1G visual/audio work.

## Delivered
### Save/resume
- Added versioned, validated save serialization in `src/save.c` / `src/save.h`.
- Save files include magic/version, CRC32 integrity check, bounds validation, full pile/face state, seed, score, move count, elapsed time and bounded undo history.
- Writes are atomic temp-file + flush + rename inside an XDG user-writable save directory (`$XDG_DATA_HOME/croupier-rx/saves` or `~/.local/share/croupier-rx/saves`).
- Main menu now offers Continue Game and Load Game; pause menu now offers Save Game and Load Game.
- Ten numbered manual slots are supported, distinct from the dedicated autosave.
- Occupied slots require overwrite confirmation; loading over an active game requires confirmation.
- Confirmed Main Menu and confirmed Select+Start Quit both autosave before leaving play.
- Save failures surface a Retry / Cancel / Quit Without Saving dialog instead of silently discarding progress.

### Quit shortcut and menus
- Added global Select+Start chord precedence without disturbing Select-only help, Start-only pause, or L2+Select undo.
- Quit confirmation is available from active gameplay and uses the autosave-on-confirm path.
- Optional controls/help bar now documents the Select+Start Quit chord.

### HUD and pile bases
- Top status bar now shows exactly `Klondike`, `Deal: N` and `Discard: N`.
- Empty stock, waste, foundation and tableau bases use darker recessed green felt wells instead of flat dark rectangles.

### Card-face lighting
- Replaced the ad-hoc deck builder with a deterministic in-repo regeneration script at `assets/source/card_fronts_v1_25pct/build_croupier_deck.py`.
- The script now reads from an immutable `assets/source/card_fronts_v1_25pct/original/` base set and regenerates:
  - lit `faces_72x100/*.png`
  - lit `faces_144x200/*.png`
  - runtime `assets/runtime/faces_72x100/*.bmp`
  - updated contact sheets and hashes
- Lighting is applied only to the connected paper field via a flood-filled mask from the card corners, preserving ranks, suits, pips, borders and court illustrations.

### Menu music
- Verified candidate source and licence:
  - FMA page: `Happy Clappy Ukulele` by Shane Ivers, licensed CC BY 4.0
  - artist page: Silverman Sound / Shane Ivers, CC BY 4.0 with required attribution
- Downloaded source MP3 to `assets/source/music/happy-clappy-ukulele.mp3`.
- Derived `assets/runtime/music/menu_theme.wav` as 24 kHz mono IMA ADPCM WAV for SDL-friendly compact playback.
- Reworked `src/audio.c` into a small software mixer so looping menu music and one-shot SFX can coexist.
- Menu music starts at launch/main menu, does not restart while navigating menus, and fades out when gameplay begins.
- Added `--mute-music` and `--music-volume 0..100` desktop controls; `--no-audio` still disables all playback.
