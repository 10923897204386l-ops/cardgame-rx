## Art source and comparison audit
- Before screenshots were captured from the unmodified M0.1F branch under `docs/screenshots/m01f/before/`.
- The title artwork was not modified.
- Permanent Marker UI font, controls, layout, card size and game rules were preserved.

## Changes made
- Replaced the runtime felt with richer emerald woven/grain texture, subtle gradient lighting, peripheral tropical flowers and a few fallen petals with contact shadows.
- Replaced default and alternate runtime backs with deep blue/gold and wine/gold floral designs. `--theme wine` still selects the alternate back.
- Regenerated all 52 runtime face BMPs from accurate Kennard-derived source PNGs with warm ivory paper, stronger keylines and preserved red/black indices/pips.
- Added lightweight deterministic SDL contact shadows behind actual cards and held stacks; empty slots no longer receive shadows.
- No gameplay rules, input controls, layout geometry, Permanent Marker font, or locked title art were changed.
