# M0.1A milestone report — 2026-11-19

Implemented on `feat/m0-1a-card-foundation`. Ready for PR review and eventual
**squash merge**, left unmerged. No changes pushed directly to main.

## Files and behavior

- `src/model.*`: validated card identity, standard deck, explicit deterministic
  Fisher–Yates shuffle, ordered pile snapshots and safe read access.
- `src/layout.*`: pure, validated layout configuration, full rectangles and
  exposed strips; default 72×100 cards with 24/12-pixel overlaps.
- `src/scene.*`: deterministic 52-identity fixtures, normal and stress.
- `src/render.*`: native pixel renderer, adjacent rank/suit indexes, conventional
  number pip counts, temporary court portraits and configurable back themes.
- `src/preview.c`: desktop window, integer scaling, preview keys, seed selection,
  exact surface capture and one-frame launch smoke mode.
- `CMakeLists.txt`, `tests/`: strict warning build, model/layout and offscreen
  rendering tests. `README.md`: setup/run/capture commands and module contracts.
- `docs/screenshots/`: normal and wine-theme stress PNG evidence at 640×480,
  losslessly converted from the executable's BMP captures.
- Project state, decisions, roadmap and task status updated for continuity.

## Local verification

Environment: Fedora 43 Toolbox in the user's desktop development environment;
GCC 15.3.1, SDL2 2.32.74. No additional packages installed during this task.

Commands completed successfully:

```sh
cmake -S . -B build/desktop -G Ninja
cmake --build build/desktop
ctest --test-dir build/desktop --output-on-failure
env -u DISPLAY -u WAYLAND_DISPLAY ctest --test-dir build/desktop --output-on-failure
./build/desktop/card-preview --smoke
./build/desktop/card-preview --scale 2 --smoke
./build/desktop/card-preview --seed random --smoke
./build/desktop/card-preview --capture build/desktop/tableau.bmp
./build/desktop/card-preview --stress --theme wine --capture build/desktop/stress.bmp
SDL_VIDEODRIVER=dummy ./build/desktop/card-preview --capture build/desktop/headless.bmp
```

CTest: **2/2 suites passed**, including 1,000 reproducible shuffled permutations,
rank/suit distribution, seed-42 reference vector, different seeds, invalid and
duplicate cards, pile order/copy/bounds, layout configuration and fixture
identity conservation. Renderer checks preserve all 52 grouped indexes under
overlap, test theme pixel changes without model mutation and check the absence
of a bottom bar. Tests remain active in Release builds (no disabled asserts).
Invalid theme command rejected with exit 2. Strict build warnings are errors.

Normal and stress captures inspected visually: crisp grouped indexes, red/black
suits, pips, clearly temporary courts and themed backs. Normal fixture fits;
stress first column extends below the canvas deliberately. Image dimensions
confirmed as 640×480. Desktop smoke launches returned success at 1× and 2×.
Dummy-video capture returned success but SDL printed inaccessible input-device
warnings; it did not require granting device access.

Optional ASan/UBSan build could not configure: the container lacks
`libasan.so.8.0.0` and `libubsan.so.1.0.0`. No sanitizer tests ran; this is not a
passing sanitizer result.

## Acceptance and limits

All scoped M0.1A local criteria are met: desktop launch, deck identity/distribution
and reproducibility, 640×480 rendering with top bar only, exposed index
legibility, pure generic model and passing display-independent tests. Evidence
is desktop-only; no hardware execution or final handheld legibility is claimed.

Window close/Escape and T/B handlers are implemented, but manual interactive
key/window-close testing was not performed; smoke mode verifies frame launch.
Full traditional court artwork is explicitly temporary as allowed by the task.
Custom image imports, final overflow strategy, rules, held-stack transactions,
undo, persistence, controller mapping and device packaging are excluded.
