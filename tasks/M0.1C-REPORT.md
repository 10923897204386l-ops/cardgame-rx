## Behavior and edge choices

Area cycle is Draw → Tableau → Foundations, reverse for L1. Each area remembers
its pile; Left/Right clamp at edges and L2/R2 jump first/last, even while holding.
Entering a pile defaults to its first face-up index. Up steps toward count−1,
Down toward the first face-up index, never hidden cards. During carry these
change destination focus/selection, never the held source/candidate.

B pickups, A waste shortcuts, navigation, preview and cancellation preserve all
authoritative piles and history. B on source cancels. A while holding cancels
and restores source focus; Select does the same without consuming undo. Invalid
drops retain candidate and cursor. Valid drops use `klondike_longest_suffix`
then `klondike_drop`; one transaction includes reveal and retains excluded
source prefixes. X uses only a selected single tableau/waste top and chooses
the first legal foundation. X/Y while holding report feedback without committing.
Y draws one or recycles in separate undo steps, with empty/no-op feedback.

Invalid B drops produce semantic `PLAY_ERROR` and a red outline around the
**entire held stack bounding box** for **300 ms**. Subsequent invalid B attempts
restart the deadline. Pure dispatch receives injected monotonic milliseconds;
SDL supplies `SDL_GetTicks64`. The app continues polling and rendering with a
16 ms bounded event wait, including when idle, so the outline expires without
new input. No blocking feedback sleep, audio library or sound playback added.

Pause gates gameplay and preserves carry. Up/Down select Resume/New Game/Quit;
A chooses. New Game defaults confirmation to No. Arrows toggle confirmation;
A on Yes deals seed+1, clears history and transient UI, and restores initial
focus. B/Start backs out of confirmation or resumes the main pause. Win is
shown in the status strip and allows Start → New Game. Window close exits.

Final keyboard defaults follow the user's correction and inspected devkit
`desktop_input.c`: physical SDL scancodes, arrows; W=X, A=Y, S=B, D=A,
Left Shift/Space=L1/R1, Left Ctrl/Left Alt=L2/R2, E=Start, Q=Select, Escape=Quit.
Pause uses A to confirm and B to back/resume. The full default table and physical
layout independence are regression-tested. Repeated `--bind action=SDLKeyName`
options remain configurable and collision checked; OS repeats are ignored.
Devkit M and Ctrl+R have no gameplay binding. Independent preview keys stay intact.


Normal table spacing is unchanged. Overflow collapses hidden cards into at most
24 pixels and uses 22-pixel face-up strips. DOWN count labels the compressed
prefix. Only the last card's lower pip art may clip, marked by an ellipsis;
all selectable indexes remain readable. Full held runs fit below the status
bar, offset from destination so its focus edge remains visible. This is minimal
desktop readability, not final overflow polish.

## Acceptance limits and review

Automated local requirements pass. **Human manual keyboard play-through was
unavailable in this shell-only input session** and remains a reviewer check.
Automated SDL key events and real one-frame launches are separate evidence;
neither is claimed as human play-testing or a complete manual win play-through.

Screenshots use temporary court art. Tall-column behavior is deliberately
minimal. Allocation injection is enabled on GNU/Linux; other compiler targets
still run retention tests but do not claim malloc injection. No sanitizers were
run for M0.1C; static analysis is not a sanitizer result.

No physical controller mapping, RG35XXSP execution, device packaging, save/resume,
audio, final court art or M0.1D work is included. Review this PR and keyboard
behavior before squash merging. Keep this report and README as continuation
context; do not start the next milestone or device work without a new request.
