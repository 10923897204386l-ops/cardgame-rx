# M0.1H — Save/resume and card-face lighting polish

Prepared 2026-11-20. User request: autosave on quit to main menu; ten manual save slots accessible during play; slightly yellower card fronts and subtle lighting. This is an implementation handoff, not evidence of completion.

## Save design
- On confirmed Quit to Main Menu, atomically write a dedicated **autosave**, then transition to menu. Show a recoverable error if saving fails; never silently discard progress. Keep autosave separate from ten manual slots.
- Main menu: Continue Game from autosave; Load Game from manual slots. Pause menu: Save Game and Load Game; provide ten numbered manual slots, with Empty or saved timestamp, move count, elapsed time and mode. Confirm overwriting a populated slot, loading over an active game and destructive new-game actions. Consider explicit Delete Slot with confirmation if low effort.
- Use a **versioned, validated save format** with magic/version, checksum or equivalent integrity guard, length/field bounds, and backward-compatible migration strategy. Use atomic temp-file + flush + rename within same directory, recover from corrupt/truncated files without crashing. Save to user-writable application data (XDG on Linux; device-specific writable path later); never write into read-only program assets or SD paths by assumption. No administrator rights needed.
- Persist full deterministic game state: original/current seed and RNG as required, all 52 card identities and ordered piles, face-up flags, stock/waste draw/recycle state, foundations, tableau, score, move count, elapsed time, game mode/draw rules, settings that affect gameplay, and bounded undo history if feasible. If undo history is not persisted, document and explicitly signal it rather than implying it survives. Reconstruct transient held selection safely, don't serialize half-completed animation or audio playback. Restore correct card orientation and legality.
- Handle win-state saves and restart semantics, pause/resume timer behavior, slot switching, corrupted saves, missing writable directory, interrupted write and clean process restart. Add roundtrip, invalid-input, version, bounds, and autosave/manual-slot independence tests. SDL-free serialization tests where possible.
- Define autosave behavior on unexpected termination separately from Quit to Main Menu; optional checkpoint autosave is not required by this request.
