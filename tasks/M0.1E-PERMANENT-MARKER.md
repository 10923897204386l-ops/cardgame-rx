# M0.1E font change — Permanent Marker (approved 2026-11-20)

**User decision: LOCKED.** Replace the current Go RX Ink/Yusei Magic gameplay and menu interface lettering with the genuine **Permanent Marker** typeface. This supersedes all previous Balsamiq/Kalam/Comic Neue font proposals. Do not change the approved Kennard cards, green felt, sparse peripheral petals, or locked Hawaiian casino title illustration.

## Implementation
1. Source the genuine Permanent Marker Regular TTF from the authoritative Google Fonts upstream repository (https://github.com/googlefonts/permanentmarker or Google Fonts family assets). Pin the exact file version/checksum in the asset manifest. Verify the actual licence shipped with that exact file; sources disagree on Apache-2.0 versus OFL-1.1, so do **not** assume OFL. Preserve upstream copyright, full licence and any NOTICE file in the repository. Never bundle a substitute font or use a screenshot as the font source.
2. Use the existing stb_truetype rendering path, font cache and asset pipeline; avoid introducing SDL_ttf or network dependencies. Apply Permanent Marker to **all user-facing interface text**: main menu, pause/confirmation/options placeholder, top status bar, optional bottom controls bar, and other UI labels. Preserve playing-card indices/suit symbols and the rasterized Kennard artwork; don't replace those with display lettering.
3. At **native 640×480**, tune font pixel sizes, baseline, tracking, kerning, contrast, vertical centring and available text widths so labels and changing values (moves/time/score) fit without clipping. This is a display face with thick strokes: use sensible smaller-size fallback only if a specific string cannot be legibly rendered; if fallback is needed, report it explicitly for approval, not silently.
4. Preserve Select toggling bottom help bar, hidden by default, and L2+Select Undo. Ensure dynamic actual key labels remain readable and correct. Preserve the top bar, game rules, keyboard mapping, art, controls and all focus/held-stack behavior.
5. Add or extend offscreen rendering tests for the new font, glyph coverage, fallback behavior, missing font asset, status bar width, menus and controls bar; capture genuine 640×480 screenshots for both bar states and menu. Run strict desktop CTest 6/6 baseline and SDL-free Release 4/4 baseline plus new tests; report actual results.
6. Update README, asset manifest, M0.1E report and PROJECT_STATE/ROADMAP as appropriate. Use a small focused commit in the active M0.1E feature branch, or create a dedicated short-lived branch from current main if none exists. Open PR for review; do not merge automatically. Do not start device packaging.

## Acceptance
- A human viewing the **running game**, not an AI mockup, can clearly identify the Permanent Marker lettering in the menu, top bar and optional bottom bar.
- All UI strings fit at native resolution, including nonzero counters and alternate key names.
- Card graphics, felt and title art remain pixel-identical except for interface text and necessary local layout adjustment.
- Tests pass; screenshots and provenance/licence documented.
