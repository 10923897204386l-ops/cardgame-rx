## Deliverables in small, reviewable commits
1. **Spatial D-pad navigation** (SDL-free policy and tests). Replace M0.1C area-cycling as primary navigation; existing L/R shortcuts may remain optional. D-pad arrows move to actual visually adjacent card positions, including while carrying. For tableau, default focus on the bottommost/top-playable face-up card; UP moves to the immediately higher exposed face-up card (underneath it in the pile), DOWN to the lower one. When UP passes the highest selectable face-up card, enter the upper row at the nearest logical target; DOWN from upper row returns to nearest tableau. No hidden cards selectable. LEFT/RIGHT move between tableau columns, maintaining approximate visual Y where feasible. Upper row horizontal order must be **stock → waste → foundations**; LEFT from first foundation goes waste then stock. Wrap at row edges and handle empty slots deterministically. Foundations: only their top card or empty destination slot is selectable; never buried cards. When carrying, navigation changes destination focus only; the authoritative model stays unchanged until atomic drop. Maintain invalid-drop red-outline 300 ms. Test each transition, edges, wrap, tall fans, empty piles, held states, undo and focus after reveal.

M0.1C already has a functional pause overlay; extend it, don't replace rules. No misleading persistent Continue if saves aren't implemented: session-only Resume/Continue is fine when game remains in memory. Use controller and keyboard consistently; no gameplay events while menus open; preserve held stack across Resume.
